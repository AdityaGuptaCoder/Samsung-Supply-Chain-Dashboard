# Samsung Supply Chain & Logistics Dashboard 📊

## Project Overview
This project is an interactive Power BI dashboard designed to analyze and visualize the supply chain and logistics data for Samsung. It provides high-level insights into supplier performance, inventory valuation, shipment delays, and overall revenue generation. 

## 📸 Dashboard Preview
![Dashboard Preview](Images/image_076b95.jpg)

## 🛠️ Tools & Technologies Used
* **Power BI:** Data ingestion, data modeling, DAX calculations, and interactive visualizations.
* **Data Sources:** Folder integration of multiple CSV files (Fact and Dimension tables).

## 🗄️ Data Model
A robust Star Schema was implemented to connect various fact tables (Inventory, Sales, Production, Procurement, Shipment) with dimension tables (Customer, Date, Facility, Product, Supplier). 

![Data Model](Images/image_0766df.png)

## 📈 Key Insights & KPIs
* **Total Revenue:** Calculated net and gross revenue metrics (e.g., 176.95M Gross Revenue).
* **Supplier Performance:** Analyzed average lead times by supplier to identify supply chain bottlenecks.
* **Shipment Tracking:** Monitored total delayed shipments segmented by carrier (Maersk, DHL, DB Schenker, etc.).
* **Inventory Valuation:** Assessed inventory value against specific product lines (Galaxy S24, Galaxy Buds, etc.).
